# Contributing

Thank you for looking. Contributions here start small, and the most useful one is telling the maintainer what is wrong or unclear.

- **Found a mistake, a command that failed, or have a question?** Open an issue. The step-by-step is on the wiki page [Give feedback and open an issue](https://github.com/ChiefGyk3D/Clouds-Against-Humanity/wiki/Give-Feedback-and-Open-an-Issue), and the same page is in the repository at [docs/wiki/Give-Feedback-and-Open-an-Issue.md](docs/wiki/Give-Feedback-and-Open-an-Issue.md). Reading, the exercises and feedback are all free.
- **Never paste** tokens, API keys, account or tenant names, real IP addresses or hostnames, an amateur radio callsign or grid square, or anything from a real vendor console that identifies you.
- **Security problems** go through [SECURITY.md](SECURITY.md), not a public issue.
- **Want to send a change?** Corrections to the wiki are welcome as pull requests (edits in the wiki editor are overwritten on the next publish). How work is planned, sized and reviewed is on [How this project is planned](docs/wiki/How-This-Project-Is-Planned.md); the pull request basics are in [Git, GitHub and pull requests](docs/wiki/Git-GitHub-and-Pull-Requests.md). Opening an issue first is a good idea for anything larger than a typo.
- Spelling is American English, and the tests will tell you if the checks fail: `python -I -m pytest tests -q`.
