## Arithmetic (730 h/month, us-east-1)

- 2 x t4g.micro: 2 x 0.0084 x 730 = $12.26
- 2 x public IPv4: 2 x 0.005 x 730 = $7.30
- 2 x 8 GiB gp3: 2 x 8 x 0.08 = $1.28 (assumes 8 GiB default, UNVERIFIED)
- Total: $20.84/mo (vs DO about $12: +$8.84, 1.7x; vs $30 ceiling: $9.16 headroom)
- Variants: t4g.nano $6.13 + 7.30 + 1.28 = $14.71; t3.micro $15.18 + 7.30 + 1.28 = $23.76
- Excludes: data transfer out, CloudWatch, any NAT ($36.50+/mo, which alone would breach the $30 ceiling).

## Summary of surprises

1. Public IPv4 is the surprise cost: $7.30/mo for two, more than half the DO total, and auto-assigned IPs are charged exactly like Elastic IPs.
2. Cheapest design is public subnet + IGW + SG with zero inbound; NAT (at least $36.50/mo with its IP) is more expensive than the whole stack and alone exceeds $30.
3. "Zero public inbound ports" on AWS is enforced by an empty-inbound SG while the instance still has a public address, same trust model as the DO firewall. A truly address-less private subnet needs NAT or endpoints.
4. Floor is about $14.71 (t4g.nano) to $20.84 (t4g.micro): above the $12 DO figure, under $30. t4g.micro recommended; nano sits at Twingate's 512 MB floor.
5. Free Tier is no longer 12-month for new accounts: $100+$100 credits, Free plan closes the account at 6 months or credit exhaustion (content kept 90 days), and it auto-upgrades to Paid if you join Organizations. A time-boxed apply fits, but warn learners the account itself expires.
6. The 750 h/mo free public IPv4 allowance is only documented for the old 12-month model; do not assume it for new accounts.
7. Twingate: only Ubuntu LTS officially supported, and docs say "ARM-based" in general but never state an arm64 connector package; verify before choosing t4g, else use t3.micro ($23.76).
8. Budget actions can apply IAM/SCP policies or target EC2/RDS instances, they do not tear down a stack; two action budgets free. Alerts are not a hard cap.
9. Spacelift needs a role trusting Spacelift's own AWS account with a per-stack external ID; the learner must create this IAM role first, so the admin identity step precedes any Spacelift apply.
10. Unverified: Ubuntu AMI default root size (assumed 8 GiB), free-plan EC2 eligible instance types, whether budget actions can "stop" (only "target" EC2/RDS shown), Twingate arm64 package.
