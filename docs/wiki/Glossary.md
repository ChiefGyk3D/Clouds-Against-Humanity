# Glossary

Every term the wiki uses, in plain language, with a pointer to the page that explains it properly. Terms a newcomer is likely to meet first are marked **(basics)**; the start-from-zero pages introduce them in order, beginning at [Start here if you are new](Start-Here-If-You-Are-New.md).

| Term | Meaning |
|---|---|
| **ACL** | Access control list: a list of who may reach what. In Twingate, a signed list of the resources a client (or connector) is allowed to reach. [Twingate: the four pieces](Twingate.md#the-four-pieces) |
| **Active provider** | A cloud marked `active: true` in `docs/stages/approved.json`, meaning it is applied right now. The active providers' approved figures must together fit under the current phase's ceiling. [CI, tests and the cost gate](CI-Tests-and-Cost-Gate.md#the-cost-gate) |
| **API** (basics) | Application programming interface. Here: the web interface a cloud provider exposes so programs can create and change resources. Everything the web console does is an API call underneath. [What is the cloud](What-Is-the-Cloud.md) |
| **API token** (basics) | A long random string that authenticates a program to an API. As powerful as a password, and usually less protected. [Identity, secrets and zero trust](Identity-Secrets-and-Zero-Trust-Basics.md) |
| **Apply** (basics) | The OpenTofu step that carries out a plan and changes real infrastructure. Always preceded by a plan a human has read. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md) |
| **Application service (appservice)** | A Matrix component the homeserver trusts to act for many users. The homeserver pushes events to it over HTTP, so it must be reachable from the homeserver. Bridges are application services. **Planned, not built:** it belongs to the stage 3 bridge design. [Roadmap: stage 3](Roadmap.md#stage-3-workloads-planned) |
| **Argument** | The extra words after a command's name that say what to work on (`ls /tmp`) or how (`-l`). The shell splits a command line on spaces before the program sees it, so quote anything with a space. [The terminal and your first script](Terminal-and-Your-First-Script.md#what-a-terminal-a-shell-a-prompt-and-a-command-are) |
| **Asymmetric encryption** | Encryption with a key pair: the public key locks, only the private key unlocks. Slow and for small data, so real tools use it to protect a symmetric key. [Hashing, encryption and keys: asymmetric](Hashing-Encryption-and-Keys.md#asymmetric-a-key-pair) |
| **ATT&CK** | MITRE ATT&CK, a public catalog of attacker techniques. Used to ask which techniques a set of detection rules does not cover. [Build your own mini SOC: keep tinkering](Build-Your-Own-Mini-SOC.md#keep-tinkering) |
| **Authentication / authorization** (basics) | Who are you? versus What may you do? Two different questions; a system can get one right and the other wrong. [Identity, secrets and zero trust](Identity-Secrets-and-Zero-Trust-Basics.md) |
| **auto.tfvars** | A value file name (`*.auto.tfvars`) that OpenTofu loads by itself. The repository ignores it like any `*.tfvars`, and the committed example is deliberately not named this way. [Variables, tfvars and secrets](Variables-Tfvars-and-Secrets.md#why-tfvars-is-ignored-and-example-is-committed) |
| **Bash** | The most common shell on Linux, also available on macOS and in WSL. The shell this wiki uses for its scripts. [The terminal and your first script](Terminal-and-Your-First-Script.md#pick-your-track) |
| **Bearer token** (basics) | A credential where whoever holds it is let in, sent as `Authorization: Bearer <token>`. The word describes how it is used, not what it is. [APIs and tokens: kinds of credential](APIs-and-Tokens-From-Zero.md#the-kinds-of-credential-side-by-side) |
| **Branch** (basics) | A parallel line of history in git. Work happens on a branch and is merged into `main` through a pull request. [Git, GitHub and pull requests](Git-GitHub-and-Pull-Requests.md) |
| **Branch protection** | A GitHub setting that stops direct pushes to `main`: changes need a pull request with passing checks. [Git, GitHub and pull requests: branch protection](Git-GitHub-and-Pull-Requests.md#branch-protection-and-one-writer) |
| **Bridge** | Software that relays messages between two chat networks, here Discord and Matrix. Planned for stage 3, not built. [Roadmap: stage 3](Roadmap.md#stage-3-workloads-planned) |
| **Bucket** (basics) | A container of files in object storage, reached over HTTPS with an access key. DigitalOcean's product is Spaces. [What is the cloud](What-Is-the-Cloud.md#what-a-cloud-provider-actually-sells) |
| **CD** | Continuous delivery: an approved change is carried towards the real system by automation, with a person deciding the last step. Here, Spacelift plans from `main` and a human confirms the apply. Continuous *deployment* has no person in between; this project does not do that. [From commit to pipeline](From-Commit-to-Pipeline.md#the-idea-in-three-words) |
| **Certificate (TLS)** | A small file saying "this public key belongs to this name", signed by a certificate authority your browser or system already trusts. The padlock on a website checks one. [Hashing, encryption and keys: certificates](Hashing-Encryption-and-Keys.md#key-pairs-in-the-wild-ssh-keys-and-tls-certificates) |
| **CGNAT** | Carrier-grade NAT: your internet provider shares one public address among many customers, so you have no address of your own to forward a port to. Breaks a home VPN server; outbound connectors are unaffected. [Zero trust at home: VPN versus ZTNA](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#vpn-versus-ztna-under-real-residential-conditions) |
| **CI** (basics) | Continuous integration: automated checks that run on every proposed change and report pass or fail. Here CI only tests; it never changes infrastructure. [CI, tests and the cost gate](CI-Tests-and-Cost-Gate.md) |
| **CIDR** (basics) | A range of IP addresses written as a start address and a slash number, such as `10.78.0.0/24` (256 addresses). `0.0.0.0/0` means every address. [Networking basics](Networking-Basics-for-This-Project.md) |
| **ClickOps** | Building infrastructure by clicking in a web console. The thing infrastructure as code replaces. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md#the-problem-clickops) |
| **Clone** (basics) | Download a repository, with its whole history, from GitHub to your computer. [Git from zero: clone your fork](Git-From-Zero.md#clone-your-fork) |
| **cloud-init** | The standard tool that configures a Linux cloud machine on its first boot from a text file (its user-data) handed over at creation. [Droplet hardening](Droplet-Hardening.md) |
| **Cloud firewall** (basics) | A firewall that runs in the provider's network, outside the machine, so the machine cannot turn it off. Attached here by tag. [DigitalOcean network and firewalls](DigitalOcean-Network-and-Firewalls.md) |
| **Commit** (basics) | One recorded set of changes in git, with a message saying why. [Git, GitHub and pull requests](Git-GitHub-and-Pull-Requests.md#git-a-history-of-every-change) |
| **Connector** | Twingate's component inside your network. Makes outbound connections only and forwards authorized traffic to resources. Here, two small droplets. [Twingate](Twingate.md) |
| **Container** (basics) | An isolated process that sees its own filesystem and network but shares the host's kernel. Lighter than a virtual machine, less isolated. [Containers and Docker basics](Containers-and-Docker-Basics.md) |
| **Controller** | Twingate's hosted coordinator: configuration, sign-in, signed ACLs. Never carries traffic. [Twingate: the four pieces](Twingate.md#the-four-pieces) |
| **Cost gate** | `scripts/cost_check.py`, which fails CI if planned spend exceeds the approved total or an unpriced paid resource appears. [How money works in the cloud](How-Money-Works-in-the-Cloud.md) |
| **Credit specification** | An AWS setting on burstable (T-family) instances: `standard` stops at the credit balance, `unlimited` bills surplus credits outside the fixed price. The cost gate requires `standard`. [Terraform reference: AWS modules](Terraform-Reference.md) |
| **cron** | The Linux and macOS scheduler that runs a command at set times. A trigger for a script. [The terminal and your first script: automation](Terminal-and-Your-First-Script.md#automation-is-a-script-plus-a-trigger) |
| **Data source** | In OpenTofu, something that already exists and is looked up rather than created. The admin SSH key here. [Lessons learned: the SSH key that already existed](Lessons-Learned.md#3-the-ssh-key-that-already-existed) |
| **DDNS** | Dynamic DNS: a name that is updated to follow a home connection's changing public address, so a VPN server can be found. Not needed by an outbound-only connector. [Zero trust at home: VPN versus ZTNA](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#vpn-versus-ztna-under-real-residential-conditions) |
| **Default deny** (basics) | Block everything, then allow only what is needed. Fails safe: a forgotten rule breaks something instead of exposing something. [Enterprise habits: default deny](Enterprise-Engineering-Habits.md#default-deny-and-attach-protection-before-the-thing-exists) |
| **DevOps** | The habit of writing down and automating how a change reaches a running system, so nobody has to remember the steps. Not a tool. [From commit to pipeline](From-Commit-to-Pipeline.md) |
| **DevSecOps** | DevOps with the security checks built into the chain (secret scanning, tests, policies, a human gate) instead of added at the end. [From commit to pipeline](From-Commit-to-Pipeline.md) |
| **DFD** | Data flow diagram: actors, processes, data stores and the flows between them, with trust boundaries drawn on it. Threat Dragon draws one. [Threat Dragon exercise](Threat-Dragon-Exercise.md#step-1-draw-your-own-first) |
| **Digital signature** | Data signed with a private key and checked with the matching public key. Proves who signed it and that it has not changed since; hides nothing. [Hashing, encryption and keys: signatures](Hashing-Encryption-and-Keys.md#digital-signatures-proof-of-who-and-what) |
| **Disposable** (basics) | A machine that holds nothing irreplaceable and can be destroyed and rebuilt from code at any time. "Stateless" means roughly the same. [How money works: destroy order](How-Money-Works-in-the-Cloud.md#6-destroy-order-and-nothing-irreplaceable) |
| **Distro (distribution)** (basics) | A kernel plus the commands, package manager, defaults and support around it, maintained by one project or vendor. Ubuntu, RHEL and SUSE are distros. [Linux for enterprise beginners](Linux-for-Enterprise-Beginners.md#why-linux-and-what-a-distro-is) |
| **DMZ** | Demilitarized zone: a network segment between the internet and the inside, where a machine that must accept inbound connections lives, so that a break-in there does not land directly on the private network. The public edge in the [Roadmap](Roadmap.md) is planned, not built. |
| **dnf / apt / zypper** | The package managers of the Red Hat family, the Debian family and SUSE. They install and update software from the distro's repositories. [Linux for enterprise beginners: packages](Linux-for-Enterprise-Beginners.md#packages) |
| **Doppler** | Hosted secrets manager. Every real secret in this project lives there. [Doppler and secrets](Doppler-and-Secrets.md) |
| **Drift** | Reality no longer matching the code because something was changed by hand. The next plan shows it. [What is infrastructure as code: drift](What-Is-Infrastructure-as-Code.md#drift) |
| **Droplet** (basics) | A DigitalOcean virtual machine. [What is the cloud](What-Is-the-Cloud.md) |
| **East-west / north-south** | Traffic between machines inside a network versus traffic between the network and the internet. Good cloud designs filter both. [Networking basics: a VPC](Networking-Basics-for-This-Project.md#a-vpc-your-own-private-network-in-the-datacenter) |
| **Encoding** | Writing data in another form so a system can carry or read it (base64, hex). Reversible by anyone with no key, so it is not secrecy. [Hashing, encryption and keys: the four things](Hashing-Encryption-and-Keys.md#the-four-things-beginners-mix-up) |
| **Encryption** | Scrambling data with a key so only the key holder can read it. Reversible with the key. Does not by itself prove the data was not changed. [Hashing, encryption and keys](Hashing-Encryption-and-Keys.md#encryption-keeping-it-secret) |
| **Environment variable** (basics) | A named value that every program you start can read, such as `HOME` or `PATH`. Often how a secret reaches a program. [The terminal and your first script](Terminal-and-Your-First-Script.md#environment-variables-and-path) |
| **Exit code** (basics) | The number a command hands back when it finishes: `0` means success, anything else means failure. CI reads this number, not the text. [The terminal and your first script](Terminal-and-Your-First-Script.md#exit-codes-and-why-ci-lives-on-them) |
| **Failover** | Traffic moving to a standby part when the active one fails: the second connector, or the cellular link. [Zero trust at home: why two connectors](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#why-two-connectors) |
| **Fingerprint (key)** | A hash of a public key, short enough to compare by eye. SSH shows the server's the first time you connect. `ssh-keygen -lf` prints yours. [Hashing, encryption and keys: the host fingerprint prompt](Hashing-Encryption-and-Keys.md#key-pairs-in-the-wild-ssh-keys-and-tls-certificates) |
| **firewalld / ufw / nftables** | Three layers of Linux host firewall: nftables is the kernel engine, firewalld and ufw are managers on top of it. [Linux for enterprise beginners: firewalls](Linux-for-Enterprise-Beginners.md#firewalls) |
| **Fork** (basics) | Your own copy of someone else's repository, kept on GitHub under your account, so you can change it freely and propose the changes back. [Git from zero: make your own copy](Git-From-Zero.md#step-2-make-your-own-copy-a-fork) |
| **Functions (DigitalOcean)** | DigitalOcean's serverless product, the equivalent of AWS Lambda: a piece of code that runs on a schedule or a request and is billed by the GiB-second, with a free monthly allowance. Deployed with `doctl`, not OpenTofu. [Containers and Docker basics: serverless](Containers-and-Docker-Basics.md#serverless-the-container-you-do-not-run) |
| **Git** (basics) | A program that records every version of the files in a folder. It works on your computer with no website. [Git from zero](Git-From-Zero.md#git-and-github-are-not-the-same-thing) |
| **GitHub CLI (`gh`)** (basics) | A command-line program from GitHub that signs you in through the browser and can open pull requests. [Git from zero: HTTPS or SSH](Git-From-Zero.md#https-or-ssh-and-why-start-with-gh) |
| **GYST** | git-your-ship-together, the author's library of reusable, hardened GitHub Actions workflows. [CI, tests and the cost gate](CI-Tests-and-Cost-Gate.md#call-shared-workflows-do-not-copy-them) |
| **Hash** | A fixed-size fingerprint of any data, the same every time for the same input and unrelated after a one-character change. One way: you cannot get the data back. Also called a digest. [Hashing, encryption and keys: hashing](Hashing-Encryption-and-Keys.md#hashing-a-fingerprint-not-a-lock) |
| **HCL** (basics) | HashiCorp Configuration Language, the language Terraform and OpenTofu files are written in. Blocks, names and values. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md#terraform-opentofu-and-why-both-names-appear) |
| **HEAD / detached HEAD** | HEAD is git's name for where you are now, normally a branch. Detached means it points at one old commit, not a branch. [Git from zero: detached HEAD](Git-From-Zero.md#4-you-are-in-detached-head-state) |
| **High availability (HA)** | Designing so one failed part does not stop the service, usually by running two. [Zero trust at home: why two connectors](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#why-two-connectors) |
| **HMAC** | A hash mixed with a secret key, so only someone with the key can produce or check it. Use it instead of a home-made `hash(secret + message)`. [Hashing, encryption and keys](Hashing-Encryption-and-Keys.md#which-hash-to-use) |
| **HTTP status code** (basics) | The number at the start of a response: 2xx worked, 3xx look elsewhere, 4xx your request was wrong (401 unknown who you are, 403 known but not allowed), 5xx the server broke. [APIs and tokens: HTTP](APIs-and-Tokens-From-Zero.md#http-in-ten-minutes) |
| **Hypervisor** | The software on a physical server that splits it into virtual machines. [What is the cloud: a virtual machine](What-Is-the-Cloud.md#a-virtual-machine-a-little-more-precisely) |
| **IaC** (basics) | Infrastructure as code: describing an environment in text files that a tool turns into real resources. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md) |
| **Idempotent** | Safe to run again: applying the same configuration twice changes nothing the second time. [What is infrastructure as code: declarative](What-Is-Infrastructure-as-Code.md#declarative-not-a-script) |
| **IdP** (basics) | Identity provider, the one service that actually checks who you are and enforces MFA, used by everything else to sign people in. [Identity basics: MFA and identity providers](Identity-Secrets-and-Zero-Trust-Basics.md#mfa-and-identity-providers) |
| **Image** (basics) | A frozen filesystem with a program and its dependencies, from which containers are started. Published to a registry such as `ghcr.io`. [Containers and Docker basics](Containers-and-Docker-Basics.md#images-registries-containers) |
| **IMDSv2** | The session-token version of the AWS instance metadata service. Required on the AWS connector, with a hop limit of 1, so a plain request cannot read the metadata. [Terraform reference: AWS modules](Terraform-Reference.md) |
| **Inbound / outbound** (basics) | From a machine's view: connections others open toward it, versus connections it opens toward others. This project's droplets allow zero inbound. [Networking basics](Networking-Basics-for-This-Project.md) |
| **Instance profile** | The AWS wrapper that lets an EC2 instance carry an IAM role. The AWS connector deliberately has none, so there is no cloud credential on the machine to steal. [AWS: the same four pieces](Provider-AWS-The-Same-Four-Pieces.md) |
| **instance_of** | The field in a stack instance manifest that names the base stack whose code it reuses; the cloud and machine count are taken from that stack. [Multiple sites: how the cost gate sees a second site](Multiple-Sites-and-Identity.md#how-the-cost-gate-sees-a-second-site) |
| **IP address** (basics) | A device's number on a network. Private addresses (`10.x`, `172.16-31.x`, `192.168.x`) work only inside one network; public addresses are unique worldwide. [Networking basics: addresses](Networking-Basics-for-This-Project.md#addresses-public-and-private) |
| **JSON** (basics) | JavaScript Object Notation: plain-text data made of objects (`{}`), arrays (`[]`), strings, numbers, true, false and null. How most APIs write data. [APIs and tokens: JSON](APIs-and-Tokens-From-Zero.md#json-in-five-minutes) |
| **Jump host** | A machine you log in to first and then hop from to reach others. A connector in front of an agentless device removes the need for one. [Zero trust at home: the agentless-device case](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#the-agentless-device-case) |
| **JWT** (basics) | JSON Web Token: a signed token of three dot-separated parts (header, claims, signature). The first two are base64 text anyone can read, so never paste a real one anywhere. [APIs and tokens: inside a JWT](APIs-and-Tokens-From-Zero.md#what-is-inside-a-jwt-and-why-base64-is-not-encryption) |
| **Kernel** | The core of an operating system that talks to the hardware and shares it among programs. Linux is a kernel; a distro adds the rest. [Linux for enterprise beginners](Linux-for-Enterprise-Beginners.md#why-linux-and-what-a-distro-is) |
| **Key pair** | A private key you guard and a public key you share, mathematically linked. Used for SSH logins, signatures and TLS. See also Public key / private key. [Hashing, encryption and keys](Hashing-Encryption-and-Keys.md#asymmetric-a-key-pair) |
| **Lateral movement** | An attacker moving from the first compromised system to others on the same network. [Threat model](Threat-Model.md#threats-controls-residual-risk) |
| **Least privilege** (basics) | Give each person and program the smallest set of permissions that lets it do its job. [Identity basics: least privilege](Identity-Secrets-and-Zero-Trust-Basics.md#least-privilege) |
| **LINDDUN** | A privacy-focused threat categorization, like STRIDE but for privacy threats. Named, not used, in this wiki. [Threat Dragon exercise](Threat-Dragon-Exercise.md#what-was-checked-and-what-was-not) |
| **Linter** | A tool that reads a script or file without running it and warns about common mistakes. ShellCheck for Bash, PSScriptAnalyzer for PowerShell. [The terminal and your first script](Terminal-and-Your-First-Script.md#lint-it) |
| **Listening** (basics) | A program waiting for connections on a port. Only listening programs can be attacked over the network. [Networking basics: ports and listening](Networking-Basics-for-This-Project.md#ports-and-listening) |
| **LTS** | Long Term Support: a release a vendor promises to patch for years. Ubuntu 24.04 LTS is the image this project uses. [Linux for enterprise beginners: lifecycle](Linux-for-Enterprise-Beginners.md#patching-and-why-lifecycle-dates-matter) |
| **MAC (mandatory access control)** | A second set of rules, set by the system, about which program may touch which thing; SELinux and AppArmor are the two Linux ones. Never disable them to fix a problem. [Linux for enterprise beginners](Linux-for-Enterprise-Beginners.md#selinux-and-apparmor-in-plain-language) |
| **Merge conflict** | Two changes touched the same lines and git cannot choose, so it marks the file and waits for you. [Git from zero: a merge conflict](Git-From-Zero.md#3-a-merge-conflict) |
| **MFA** (basics) | Multi-factor authentication: a second proof beyond the password, such as a code from an app or a hardware key. [Identity basics: MFA and identity providers](Identity-Secrets-and-Zero-Trust-Basics.md#mfa-and-identity-providers) |
| **Module** | A reusable OpenTofu building block: a folder of HCL that does one thing and takes inputs. Never applied on its own here. [OpenTofu, stacks and modules](OpenTofu-Stacks-and-Modules.md) |
| **NAT gateway** | A managed service that lets machines with no public address reach out. Textbook for private machines, but about $33 to $37 a month on AWS or Azure, so the cost gate refuses it. [AWS: where the money goes](Provider-AWS-Cost-Lesson.md) |
| **NOC / SOC / SIEM** | A team that watches whether things are up (network operations center), a team that watches whether anything is suspicious (security operations center), and the tool that collects and searches the events (security information and event management). [Cloud telemetry: NOC, SOC and SIEM](Cloud-Telemetry-What-and-Why.md#noc-soc-and-siem-a-team-a-team-and-a-tool) |
| **Nonce** | A number used once per message in many encryption modes. Reusing one with the same key can break the encryption; let the library pick it. [Hashing, encryption and keys: not secure](Hashing-Encryption-and-Keys.md#encrypted-is-not-secure) |
| **NSG** | Network security group, Azure's firewall filter, attached to a subnet or a network interface. [Azure: the same four pieces](Provider-Azure-The-Same-Four-Pieces.md#piece-2-the-firewall) |
| **Object storage** (basics) | File storage reached over HTTPS, paid per gigabyte, with no operating system to manage. S3 is the common name; Spaces is DigitalOcean's. [What is the cloud](What-Is-the-Cloud.md#what-a-cloud-provider-actually-sells) |
| **OIDC** | OpenID Connect. Here: short-lived identity tokens that let one service authenticate to another without a stored secret. [Spacelift: no OIDC on this plan](Spacelift.md#no-oidc-on-this-plan) |
| **OpenTofu** (basics) | Open-source, MPL-licensed fork of Terraform. Same language, same providers; `tofu` instead of `terraform`. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md) |
| **Passphrase** | A long phrase that encrypts a private key file on disk, so a copied file is not a stolen identity. [Hashing, encryption and keys: keeping keys](Hashing-Encryption-and-Keys.md#keeping-keys-storage-passphrases-and-hardware-keys) |
| **PATH** (basics) | The ordered list of folders the shell searches for a program. The first match wins, so the order matters for security. [The terminal and your first script](Terminal-and-Your-First-Script.md#environment-variables-and-path) |
| **Pipe** | The `\|` character, which feeds one command's output into the next command's input. [The terminal and your first script](Terminal-and-Your-First-Script.md#read-search-and-chain-files-pipes-and-redirects) |
| **Pipeline** | The chain of gates a change passes from commit to running infrastructure: pull request, CI, review, merge, plan, human confirm, apply. [Fork, private stacks and the pipeline](Fork-Private-Stacks-and-the-Pipeline.md#where-the-pipeline-actually-starts) |
| **Plan** (basics) | The OpenTofu step that compares the code with reality and lists what would be created, changed or destroyed, without doing it. The thing a human reads before confirming. [What is infrastructure as code: plan and apply](What-Is-Infrastructure-as-Code.md#plan-and-apply) |
| **Plan no-op check** | `scripts/plan_noop_check.py`: with default values, a saved plan of an edited live stack must change nothing and name only the known resource addresses. [Variables, tfvars and secrets: the no-op plan check](Variables-Tfvars-and-Secrets.md#the-no-op-plan-check) |
| **Policy as code** | A rule such as "no firewall may accept the whole internet" written as a tested file in the repository and applied by a machine every time. Here: the cost gate, the `tofu test` files and `.spacelift/policies/plan.rego`. [From commit to pipeline](From-Commit-to-Pipeline.md#policy-as-code-rules-a-machine-can-enforce-on-every-plan) |
| **Port** (basics) | A number from 1 to 65535 that directs a packet to the right program on a machine. 22 is SSH, 443 is HTTPS. [Networking basics: ports and listening](Networking-Basics-for-This-Project.md#ports-and-listening) |
| **Portainer** | A web UI for a Docker host: stacks, containers, logs. Community Edition is free. It talks to Docker over the local socket, which is root on the host, so its UI is reached only through Twingate here. [Containers and Docker basics: Compose and Portainer](Containers-and-Docker-Basics.md#compose-and-portainer) |
| **OPA / Rego** | Open Policy Agent, a general-purpose policy engine, and Rego, the language its policies are written in. Spacelift policies are Rego; this repo tests its push policy with `opa test` in CI. [Spacelift: why a pull request gets no run](Spacelift.md#why-a-pull-request-gets-no-spacelift-run-at-all) |
| **PowerShell** | The shell and scripting language on Windows (also available on Linux and macOS). Passes objects between commands rather than plain text. [The terminal and your first script](Terminal-and-Your-First-Script.md#pick-your-track) |
| **Prompt** | The short line a shell prints to say it is ready for a command, often ending in `$` or `>`. [The terminal and your first script](Terminal-and-Your-First-Script.md#what-a-terminal-a-shell-a-prompt-and-a-command-are) |
| **Proposed run** | A Spacelift plan for a pull request. Gets no credentials in this repo, and the push policy stops Spacelift starting one at all. [Spacelift: why a pull request plan gets no credentials](Spacelift.md#why-a-pull-request-plan-gets-no-credentials) |
| **Push / pull (git)** (basics) | Push sends your commits to GitHub. Pull brings other commits down to your computer. [Git from zero: push](Git-From-Zero.md#push) |
| **Push policy (Spacelift)** | A Rego policy that decides which Git events start a Spacelift run, and whether as a tracked or proposed run. Here: `.spacelift/policies/push.rego`, which tracks merges that change a stack and never proposes. [Spacelift](Spacelift.md) |
