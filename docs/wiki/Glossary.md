# Glossary

Every term the wiki uses, in plain language, with a pointer to the page that explains it properly. Terms a newcomer is likely to meet first are marked **(basics)**; the start-from-zero pages introduce them in order, beginning at [Start here if you are new](Start-Here-If-You-Are-New.md).

| Term | Meaning |
|---|---|
| **3-2-1 rule** | Keep three copies of important data, on two kinds of media, with one copy offsite. A starting point, not a guarantee: it says nothing about whether a copy restores or how old it is. [Backups, recovery and patching: 3-2-1](Backups-Recovery-and-Patching.md#the-3-2-1-rule-and-what-it-leaves-open) |
| **AAA** | Authentication, authorization, accounting: who are you, what may you do, and what did you do. Three questions, answered by three kinds of control. [Enterprise identity](Enterprise-Identity-SSO-SAML-OIDC.md#three-questions-authentication-authorization-accounting) |
| **ABAC** | Attribute-based access control: a decision made from attributes of the person, the resource and the context (department, device state, time) rather than only a role. [Enterprise identity](Enterprise-Identity-SSO-SAML-OIDC.md#groups-roles-and-mapping-people-to-access) |
| **ACL** | Access control list: a list of who may reach what. In Twingate, a signed list of the resources a client (or connector) is allowed to reach. [Twingate: the four pieces](Twingate.md#the-four-pieces) |
| **Active Directory (AD DS)** | Microsoft's on-premises directory service: the domain's users, computers and groups, held on domain controllers, with Kerberos and Group Policy built on it. [Windows, AD and macOS](Windows-Active-Directory-and-macOS-in-the-Enterprise.md#first-the-words) |
| **Active provider** | A cloud marked `active: true` in `docs/stages/approved.json`, meaning it is applied right now. The active providers' approved figures must together fit under the current phase's ceiling. [CI, tests and the cost gate](CI-Tests-and-Cost-Gate.md#the-cost-gate) |
| **Alert fatigue** | What happens when a person gets so many alerts, mostly false, that the real one is ignored or closed in a hurry. The cure is fewer, better-tuned alerts, each with a next step. [Logs, SIEM and detection basics: alert fatigue](Logs-SIEM-and-Detection-Basics.md#alert-fatigue) |
| **Anchor (YAML)** | A label (`&name`) on a block of YAML that an alias (`*name`) can paste elsewhere, often with `<<:` to merge it in. Saves typing and makes a file harder to review; this repository's Spacelift config loader refuses them. [Data formats: anchors](Data-Formats-JSON-YAML-HCL.md#anchors-and-the-other-parts-to-be-careful-with) |
| **Apache HTTP Server** | A web server, program name `httpd` or `apache2`. Handles many visitors with a chosen multi-processing module (`prefork`, `worker`, `event`) and can read per-folder `.htaccess` files. [LAMP and LEMP from zero: the A and the E](LAMP-and-LEMP-From-Zero.md#the-a-and-the-e-two-ways-to-serve-many-visitors) |
| **Apex (zone apex)** | The bare domain, `example.com`, as opposed to `www.example.com`. It must carry the SOA and NS records, which is why a plain CNAME cannot sit there. [DNS and Cloudflare: records](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#the-records-you-will-meet) |
| **API** (basics) | Application programming interface. Here: the web interface a cloud provider exposes so programs can create and change resources. Everything the web console does is an API call underneath. [What is the cloud](What-Is-the-Cloud.md) |
| **API token** (basics) | A long random string that authenticates a program to an API. As powerful as a password, and usually less protected. [Identity, secrets and zero trust](Identity-Secrets-and-Zero-Trust-Basics.md) |
| **Apply** (basics) | The OpenTofu step that carries out a plan and changes real infrastructure. Always preceded by a plan a human has read. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md) |
| **Application service (appservice)** | A Matrix component the homeserver trusts to act for many users. The homeserver pushes events to it over HTTP, so it must be reachable from the homeserver. Bridges are application services. **Planned, not built:** it belongs to the stage 3 bridge design. [Roadmap: stage 3](Roadmap.md#stage-3-workloads-planned) |
| **Argument** | The extra words after a command's name that say what to work on (`ls /tmp`) or how (`-l`). The shell splits a command line on spaces before the program sees it, so quote anything with a space. [The terminal and your first script](Terminal-and-Your-First-Script.md#what-a-terminal-a-shell-a-prompt-and-a-command-are) |
| **Assertion (SAML)** | The signed XML statement an identity provider sends to an application: who authenticated, when, for which application, with which attributes (such as groups). [Enterprise identity](Enterprise-Identity-SSO-SAML-OIDC.md#saml-step-by-step) |
| **Asymmetric encryption** | Encryption with a key pair: the public key locks, only the private key unlocks. Slow and for small data, so real tools use it to protect a symmetric key. [Hashing, encryption and keys: asymmetric](Hashing-Encryption-and-Keys.md#asymmetric-a-key-pair) |
| **ATT&CK** | MITRE ATT&CK, a public catalog of attacker techniques. Used to ask which techniques a set of detection rules does not cover. [Build your own mini SOC: keep tinkering](Build-Your-Own-Mini-SOC.md#keep-tinkering) |
| **auditd** | The Linux audit system's daemon: it records events the kernel reports (file changes, account changes, commands) to `/var/log/audit/audit.log`. The stage 2 connectors get a short set of watch rules. [Logs, SIEM and detection basics: where logs live](Logs-SIEM-and-Detection-Basics.md#where-logs-live) |
| **Authentication / authorization** (basics) | Who are you? versus What may you do? Two different questions; a system can get one right and the other wrong. [Identity, secrets and zero trust](Identity-Secrets-and-Zero-Trust-Basics.md) |
| **Authoritative nameserver** | A server that holds a zone's records and gives the official answer for it, as opposed to a resolver that only looks answers up and caches them. [DNS and Cloudflare: names and who answers](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#names-who-owns-them-and-who-answers) |
| **auto.tfvars** | A value file name (`*.auto.tfvars`) that OpenTofu loads by itself. The repository ignores it like any `*.tfvars`, and the committed example is deliberately not named this way. [Variables, tfvars and secrets](Variables-Tfvars-and-Secrets.md#why-tfvars-is-ignored-and-example-is-committed) |
| **Autodeploy** | A Spacelift stack setting: when on, a plan with no policy warnings applies without a person pressing Confirm. This project leaves it off for every stack. [Spacelift from zero: the pieces](Spacelift-From-Zero.md#the-pieces-in-the-order-you-meet-them) |
| **Automatic updates** | Software that installs updates on a schedule without anyone clicking, such as `unattended-upgrades` or `dnf-automatic`. Installed is not the same as on: check the setting and the timer. [First hour on a new system](First-Hour-on-a-New-System-Updates-and-Baseline.md#what-automatic-updates-means-system-by-system) |
| **Availability zone** | A separate location inside a region, so one building's failure does not take down everything. AWS names one as the region code plus a letter (`us-east-1a`); DigitalOcean speaks of datacenters. [Virtual machines, containers and cloud service models: regions and availability zones](Virtual-Machines-Containers-and-Cloud-Service-Models.md#regions-and-availability-zones) |
| **Backend (state)** | Where OpenTofu keeps its state: a local file by default, or a shared store such as a bucket. Some backends lock the state during writes. [Plans, state, drift and recovery: remote state](Plans-State-Drift-and-Recovery.md#why-teams-use-remote-state) |
| **Backup** | A separate, restorable copy of data made on a schedule and kept where the original's failure does not reach. Not a snapshot on the same disk, and not a replica. A backup you have never restored is a hope. [Backups, recovery and patching](Backups-Recovery-and-Patching.md#four-words-that-sound-alike) |
| **Baseline** | A description of what normal looks like, learned from data, so a deviation can raise an alert; it catches what no one wrote a rule for, and is only as honest as the data it learned from. [Logs, SIEM and detection basics: Exercise 7](Logs-SIEM-and-Detection-Basics.md#exercise-7-a-baseline-instead-of-a-rule) |
| **Baseline (system)** | A text record of a machine's package versions, listening ports, users, services, firewall rules and hashes of key files, taken right after the first update, so later changes show up as a diff. [First hour on a new system](First-Hour-on-a-New-System-Updates-and-Baseline.md#exercise-3-take-a-baseline-drift-it-read-the-diff) |
| **Bash** | The most common shell on Linux, also available on macOS and in WSL. The shell this wiki uses for its scripts. [The terminal and your first script](Terminal-and-Your-First-Script.md#pick-your-track) |
| **Bearer token** (basics) | A credential where whoever holds it is let in, sent as `Authorization: Bearer <token>`. The word describes how it is used, not what it is. [APIs and tokens: kinds of credential](APIs-and-Tokens-From-Zero.md#the-kinds-of-credential-side-by-side) |
| **Blameless post-mortem** | A short written account of an incident that names contributing causes in the system, process and tools, without blaming a person, so people can report what happened. [Working in a company: the post-mortem](Working-in-a-Company-Tickets-Change-On-Call-and-Documentation.md#5-a-short-blameless-post-mortem) |
| **Blast radius** | How much can go wrong when one thing fails or is changed by mistake. A stack's blast radius is what is in its state; splitting an environment into stacks makes each radius smaller. [Build and destroy a bunch: why one stack per service](Build-and-Destroy-Stack-Per-Service.md#why-one-stack-per-service) |
| **Blue team** | The defenders: the people who run, monitor and protect the systems and are the side that has to notice an attack. Half of the maintainer's red-and-blue picture. [Red and blue as yin and yang](Red-and-Blue-Yin-and-Yang-and-Your-Lab-OS.md#red-and-blue-and-the-idea-of-yin-and-yang) |
| **Branch** (basics) | A parallel line of history in git. Work happens on a branch and is merged into `main` through a pull request. [Git, GitHub and pull requests](Git-GitHub-and-Pull-Requests.md) |
| **Branch protection** | A GitHub setting that stops direct pushes to `main`: changes need a pull request with passing checks. [Git, GitHub and pull requests: branch protection](Git-GitHub-and-Pull-Requests.md#branch-protection-and-one-writer) |
| **Breadcrumb** | A lure planted on a real machine, such as a fake saved login, to pull an intruder sideways toward a decoy. [What deception is](Deception-and-Honeypots-What-Deception-Is.md#the-vocabulary) |
| **Break-glass** | A powerful account that is normally locked and can be opened in an emergency; opening it is loud, time-limited and reviewed afterward. [Enterprise change management: emergency changes and break-glass](Enterprise-Change-Management-for-Beginners.md#emergency-changes-and-break-glass) |
| **Bridge** | Software that relays messages between two chat networks, here Discord and Matrix. Planned for stage 3, not built. [Roadmap: stage 3](Roadmap.md#stage-3-workloads-planned) |
| **Bucket** (basics) | A container of files in object storage, reached over HTTPS with an access key. DigitalOcean's product is Spaces. [What is the cloud](What-Is-the-Cloud.md#what-a-cloud-provider-actually-sells) |
| **Burp Suite** | PortSwigger's web testing toolkit. The free Community Edition has an intercepting proxy, Repeater and other manual tools; its scanner is in the paid Professional edition. [Security tools basics](Security-Tools-Basics-Nmap-OpenVAS-Burp-Metasploit.md#burp-suite-community-edition-and-owasp-zap) |
| **CA (certificate authority)** | An organization that signs certificates after checking that the requester controls the name. Clients trust a CA because its certificate is in their trust store. [How a web request works: the chain of trust](How-a-Web-Request-Works.md#who-vouches-for-the-issuer-the-chain-of-trust) |
| **CAA record** | A DNS record that lists the certificate authorities allowed to issue certificates for a domain. [DNS and Cloudflare: records](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#the-records-you-will-meet) |
| **Canarytoken** | Also canary token. A honeytoken built so that opening or using it sends you a message: a document with a link, or a fake key. It reveals when, from which address and by which client, not who. [Plant a canary token](Deception-and-Honeypots-Plant-a-Canary.md#what-a-canary-token-is) |
| **CD** | Continuous delivery: an approved change is carried towards the real system by automation, with a person deciding the last step. Here, Spacelift plans from `main` and a human confirms the apply. Continuous *deployment* has no person in between; this project does not do that. [From commit to pipeline](From-Commit-to-Pipeline.md#the-idea-in-three-words) |
| **CDN** | Content delivery network: many servers around the world that hold copies of a site's files so a visitor is answered from a nearby copy. [How a web request works](How-a-Web-Request-Works.md#caching-cdns-proxies-and-load-balancers-a-sentence-each) |
| **Certificate** (basics) | A signed statement that a public key belongs to a name, valid between two dates, signed by an issuer. It is what a client checks during the TLS handshake. [How a web request works: certificates](How-a-Web-Request-Works.md#certificates-and-trust-chains-in-plain-language) |
| **Certificate (TLS)** | A small file saying "this public key belongs to this name", signed by a certificate authority your browser or system already trusts. The padlock on a website checks one. [Hashing, encryption and keys: certificates](Hashing-Encryption-and-Keys.md#key-pairs-in-the-wild-ssh-keys-and-tls-certificates) |
| **CGNAT** | Carrier-grade NAT: your internet provider shares one public address among many customers, so you have no address of your own to forward a port to. Breaks a home VPN server; outbound connectors are unaffected. [Zero trust at home: VPN versus ZTNA](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#vpn-versus-ztna-under-real-residential-conditions) |
| **Cgroup** | Control group: a Linux kernel feature that limits what a process may use (memory, CPU, number of processes). With namespaces, it makes a container. [Virtual machines, containers and cloud service models: containers and images](Virtual-Machines-Containers-and-Cloud-Service-Models.md#containers-and-images) |
| **Change request (RFC)** | The written proposal for a change: what, why, risk, test evidence, rollback and approver. Standard changes are pre-approved types, normal changes are approved each time, emergency changes take a fast path and are reviewed afterward. [Working in a company: a change request](Working-in-a-Company-Tickets-Change-On-Call-and-Documentation.md#2-a-change-request-and-ten-worked-examples) |
| **CI** (basics) | Continuous integration: automated checks that run on every proposed change and report pass or fail. Here CI only tests; it never changes infrastructure. [CI, tests and the cost gate](CI-Tests-and-Cost-Gate.md) |
| **CIDR** (basics) | A range of IP addresses written as a start address and a slash number, such as `10.78.0.0/24` (256 addresses). `0.0.0.0/0` means every address. [Networking basics](Networking-Basics-for-This-Project.md); [do the arithmetic yourself](Subnets-NAT-and-Firewalls-By-Hand.md#addresses-and-cidr-by-hand) |
| **ClickOps** | Building infrastructure by clicking in a web console. The thing infrastructure as code replaces. [What is infrastructure as code](What-Is-Infrastructure-as-Code.md#the-problem-clickops) |
| **Clone** (basics) | Download a repository, with its whole history, from GitHub to your computer. [Git from zero: clone your fork](Git-From-Zero.md#clone-your-fork) |
| **cloud-init** | The standard tool that configures a Linux cloud machine on its first boot from a text file (its user-data) handed over at creation. [Droplet hardening](Droplet-Hardening.md) |
| **Cloud firewall** (basics) | A firewall that runs in the provider's network, outside the machine, so the machine cannot turn it off. Attached here by tag. [DigitalOcean network and firewalls](DigitalOcean-Network-and-Firewalls.md) |
| **CNAME flattening** | A DNS host's feature that looks up an alias target itself and answers with the final address, so an alias can be used at the zone apex. A vendor feature, not a record type. [DNS and Cloudflare: records](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#the-records-you-will-meet) |
| **Commit** (basics) | One recorded set of changes in git, with a message saying why. [Git, GitHub and pull requests](Git-GitHub-and-Pull-Requests.md#git-a-history-of-every-change) |
| **Compliance** | Meeting a rule or standard that someone else can check (a law, a contract, SOC 2, ISO 27001). Related to security but not the same thing: a report is evidence about a stated scope and period. [Threats in plain words: compliance](Threats-in-Plain-Words.md#what-soc-2-iso-27001-and-the-nist-frameworks-are-for) |
| **Conditional access** | A sign-in rule that depends on context (managed device, location, application, risk) instead of only on the password. [Enterprise identity](Enterprise-Identity-SSO-SAML-OIDC.md#conditional-access) |
| **Configuration as code** | Treating settings files like code: kept in git, changed by pull request, reviewed and validated in CI. [Data formats: config as code](Data-Formats-JSON-YAML-HCL.md#config-as-code) |
| **Configuration profile (macOS)** | A bundle of settings an MDM service pushes to a Mac or other Apple device, such as Wi-Fi, password rules or certificates; a legacy one is a `.mobileconfig` file. [Windows, AD and macOS](Windows-Active-Directory-and-macOS-in-the-Enterprise.md#macos-in-the-enterprise) |
| **Connector** | Twingate's component inside your network. Makes outbound connections only and forwards authorized traffic to resources. Here, two small droplets. [Twingate](Twingate.md) |
| **Conntrack** | Connection tracking: the Linux kernel's table of connections it has seen. A stateful firewall (`ct state established,related`) and NAT both use it. [Subnets, NAT and firewalls by hand: NAT](Subnets-NAT-and-Firewalls-By-Hand.md#nat-and-port-forwarding) |
| **Container** (basics) | An isolated process that sees its own filesystem and network but shares the host's kernel. Lighter than a virtual machine, less isolated. [Containers and Docker basics](Containers-and-Docker-Basics.md) |
| **Context (Spacelift)** | A bundle of environment variables, mounted files and hooks kept apart from any stack and attached to as many stacks as you like, by hand or by an `autoattach:` label. [Spacelift from zero](Spacelift-From-Zero.md#the-pieces-in-the-order-you-meet-them) |
| **Controller** | Twingate's hosted coordinator: configuration, sign-in, signed ACLs. Never carries traffic. [Twingate: the four pieces](Twingate.md#the-four-pieces) |
| **Cost gate** | `scripts/cost_check.py`, which fails CI if planned spend exceeds the approved total or an unpriced paid resource appears. [How money works in the cloud](How-Money-Works-in-the-Cloud.md) |
| **`count` / `for_each`** | Two ways to make several copies of one OpenTofu resource block. `count` numbers the copies by position, so removing an item in the middle shifts the rest; `for_each` names them by key, so only the removed key goes. [OpenTofu from zero: count and for_each](OpenTofu-From-Zero.md#many-copies-count-and-for_each) |
| **Cowrie** | An open-source honeypot that imitates an SSH server (and, if switched on, a telnet server): it accepts logins, answers like a Linux command line from a fake file system, and writes everything the visitor does to a JSON log. Medium interaction in its default mode. [Anatomy of a cloud honeypot](Deception-and-Honeypots-Cloud-Sensor-Anatomy.md#what-a-cloud-sensor-is) |
| **Credit specification** | An AWS setting on burstable (T-family) instances: `standard` stops at the credit balance, `unlimited` bills surplus credits outside the fixed price. The cost gate requires `standard`. [Terraform reference: AWS modules](Terraform-Reference.md) |
| **cron** | The Linux and macOS scheduler that runs a command at set times. A trigger for a script. [The terminal and your first script: automation](Terminal-and-Your-First-Script.md#automation-is-a-script-plus-a-trigger) |
| **CSV** | Comma-separated values: a table, one row per line, columns split by commas, a value with a comma wrapped in double quotes. Every value is text. [Data formats: TOML, INI, CSV and XML](Data-Formats-JSON-YAML-HCL.md#toml-ini-csv-and-xml-a-paragraph-each) |
| **CVE** | Common Vulnerabilities and Exposures: a shared ID (such as CVE-2018-13379) for one specific flaw, so vendors, scanners and government lists can all name the same thing. An ID is not a score or a fix. [Threats in plain words: reading a CVE record](Threats-in-Plain-Words.md#reading-a-cve-record-the-one-from-core-step-11) |
| **CVE** | Common Vulnerabilities and Exposures: a public ID (such as `CVE-2021-44228`) for one specific security flaw, so every vendor and scanner means the same flaw. The ID is a name; the details are in a record. [Backups, recovery and patching: reading a CVE](Backups-Recovery-and-Patching.md#reading-a-cve-entry-and-a-severity-score) |
| **CVSS** | Common Vulnerability Scoring System: a 0 to 10 severity score plus a vector spelling out each input. It measures how bad a flaw is in the abstract, not whether it is being attacked or whether you run the affected product. [Threats in plain words: CVSS](Threats-in-Plain-Words.md#cvss-what-it-says-and-what-it-does-not) |
| **CVSS** | Common Vulnerability Scoring System: a 0 to 10 severity score for a flaw in itself (Low, Medium, High, Critical bands). It does not know whether you run the software or whether anyone is attacking it. [Backups, recovery and patching: what the score does not tell you](Backups-Recovery-and-Patching.md#what-the-score-does-not-tell-you) |
| **CWE** | Common Weakness Enumeration: a catalog of kinds of software mistake (CWE-22 is path traversal). Many CVEs share one CWE. [Threats in plain words: reading a CVE record](Threats-in-Plain-Words.md#reading-a-cve-record-the-one-from-core-step-11) |
| **Data source** | In OpenTofu, something that already exists and is looked up rather than created. The admin SSH key here. [Lessons learned: the SSH key that already existed](Lessons-Learned.md#3-the-ssh-key-that-already-existed) |
| **DDNS** | Dynamic DNS: a name that is updated to follow a home connection's changing public address, so a VPN server can be found. Not needed by an outbound-only connector. [Zero trust at home: VPN versus ZTNA](Zero-Trust-at-Home-Two-Connectors-and-Failover.md#vpn-versus-ztna-under-real-residential-conditions) |
| **Decoy** | A fake resource (a server, a file, an account) that looks real, that no legitimate person or program has a reason to touch, and that is watched. [What deception is](Deception-and-Honeypots-What-Deception-Is.md#the-vocabulary) |
| **Default deny** (basics) | Block everything, then allow only what is needed. Fails safe: a forgotten rule breaks something instead of exposing something. [Enterprise habits: default deny](Enterprise-Engineering-Habits.md#default-deny-and-attach-protection-before-the-thing-exists) |
| **Default route** | The route `0.0.0.0/0`, "everything else goes this way", used only when no more specific route matches. A machine without one reaches its own subnet and nothing beyond. [Subnets, NAT and firewalls by hand: routing](Subnets-NAT-and-Firewalls-By-Hand.md#routing-in-plain-words) |
| **Delegation (DNS)** | The pointer, published by a parent zone, that says which nameservers answer for a child zone. Changing nameservers at your registrar edits it. [DNS and Cloudflare: delegation](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#delegation-how-the-world-finds-your-nameservers) |
| **Destroy** (basics) | The OpenTofu step that removes everything the state says a configuration created. `plan -destroy` previews it first. [OpenTofu from zero: the lifecycle](OpenTofu-From-Zero.md#the-lifecycle-init-fmt-validate-plan-apply-destroy) |
| **DevOps** | The habit of writing down and automating how a change reaches a running system, so nobody has to remember the steps. Not a tool. [From commit to pipeline](From-Commit-to-Pipeline.md) |
| **DevSecOps** | DevOps with the security checks built into the chain (secret scanning, tests, policies, a human gate) instead of added at the end. [From commit to pipeline](From-Commit-to-Pipeline.md) |
| **DFD** | Data flow diagram: actors, processes, data stores and the flows between them, with trust boundaries drawn on it. Threat Dragon draws one. [Threat Dragon exercise](Threat-Dragon-Exercise.md#step-1-draw-your-own-first) |
| **Digest (image)** | The permanent address of one exact image build, written `name@sha256:...`. A tag can move to a newer build; a digest cannot. [Virtual machines, containers and cloud service models: exercise 3](Virtual-Machines-Containers-and-Cloud-Service-Models.md#exercise-3-how-old-is-the-image-and-who-patches-it) |
| **Digital signature** | Data signed with a private key and checked with the matching public key. Proves who signed it and that it has not changed since; hides nothing. [Hashing, encryption and keys: signatures](Hashing-Encryption-and-Keys.md#digital-signatures-proof-of-who-and-what) |
| **Directory (identity)** | The database of people, groups and attributes that an identity provider reads, such as an LDAP server or Active Directory. [Enterprise identity](Enterprise-Identity-SSO-SAML-OIDC.md#directory-identity-provider-single-sign-on-one-picture) |
| **Disposable** (basics) | A machine that holds nothing irreplaceable and can be destroyed and rebuilt from code at any time. "Stateless" means roughly the same. [How money works: destroy order](How-Money-Works-in-the-Cloud.md#6-destroy-order-and-nothing-irreplaceable) |
| **Distro (distribution)** (basics) | A kernel plus the commands, package manager, defaults and support around it, maintained by one project or vendor. Ubuntu, RHEL and SUSE are distros. [Linux for enterprise beginners](Linux-for-Enterprise-Beginners.md#why-linux-and-what-a-distro-is) |
| **DKIM, SPF, DMARC** | Three DNS TXT-record mechanisms that let a receiving mail server check whether mail claiming to be from your domain is genuine: who may send (SPF), a signature (DKIM), and what to do on failure (DMARC). [DNS and Cloudflare: email records](DNS-Cloudflare-and-Hosting-Your-Own-Website.md#email-records-at-concept-level) |
| **DMZ** | Demilitarized zone: a network segment between the internet and the inside, where a machine that must accept inbound connections lives, so that a break-in there does not land directly on the private network. The public edge in the [Roadmap](Roadmap.md) is planned, not built. |
| **DMZ host** | A router feature that sends every unsolicited inbound connection to one inside machine, exposing all its ports. Not a real DMZ segment, and the risky way to expose a decoy.
